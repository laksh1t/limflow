## 📖 About the Project
LimFlow is designed to streamline collaboration for small teams. It handles task delegation, workspace management, and productivity tracking with a focus on security and speed.

## 🛠 Tech Stack
- **Frontend:** React (Vite), Tailwind CSS, Shadcn UI, TanStack Query
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **Security:** JWT, 2FA (Two-Factor Authentication), Email Verification
- **Visuals:** Recharts for Analytics

## ✨ Key Features
- **Multi-Tenant Workspaces:** Users can create and switch between multiple team environments.
- **Advanced Task Management:** Hierarchical structure (Workspace > Project > Task > Subtask).
- **Security First:** 2FA and disposable email blocking.
- **Real-time Analytics:** Visual dashboard for tracking project progress.

## 🚀 Getting Started
1. **Clone the repo:** `git clone https://github.com/yourusername/limflow.git`
2. **Setup Server:** `cd server && npm install`
3. **Setup Client:** `cd client && npm install`
4. **Environment Variables:** Create a `.env` file in the server folder (see `.env.example`).
5. **Run the app:** `npm run dev`
